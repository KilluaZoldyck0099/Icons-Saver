# Icons Saver

Save and restore the positions of your Windows desktop icons.

Windows loves rearranging desktop icons: you unplug a monitor, a game changes the
resolution, a driver update resets the display, and suddenly every icon is piled
into the top-left corner. **Icons Saver** takes a snapshot of exactly where every
icon sits and puts them all back with one click.
